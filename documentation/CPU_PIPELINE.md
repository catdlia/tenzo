# ⚙️ Модуль: CPU Optimization Pipeline (x86 AVX2)

Це серце компілятора, де високорівневі тензорні операції перетворюються на максимально швидкий машинний код.

## 📂 Структура файлів
*   **`FusionPass.cpp`**: Оптимізація графа на рівні MLIR.
*   **`PackingPass.cpp`**: Переупорядкування матриць у пам'яті (BLIS-style).
*   **`ExplicitMicroKernel.cpp`**: Генерація асемблерного коду через MLIR Vector Dialect.

## 🛠 Ключові етапи обробки

### 1. Операторний Fusion (`FusionPass`)
**Принцип роботи:** Шукає ланцюжки операцій (MatMul -> Bias -> ReLU) і замінює їх на одну фузовану операцію.
*   **Чому це важливо:** Це дозволяє утримувати проміжні результати в регістрах процесора, замість того щоб записувати їх назад у DRAM.
*   **Результат:** Зменшення трафіку пам'яті на 30-50%.

### 2. Пакування Матриць (`PackingPass`)
**Принцип роботи:** Процесор найшвидше читає дані послідовно. Стандартні матриці (row-major) читаються погано при множенні (по стовпцях).
*   **Метод:** Матриця B перетворюється на блок-панельну структуру, де дані, що будуть використані в одному мікро-ядерці (6x16), лежать підряд.
*   **Результат:** Стабільна швидкість обчислень (cache-friendly).

### 3. Генерація Мікро-ядра (`ExplicitMicroKernel`)
**Принцип роботи:** Створює найбільш оптимізований цикл, який виконується повністю в регістрах AVX2 (YMM0-YMM15).
*   **Реєстровий файл:**
    *   12 регістрів (YMM0-YMM11) — акумулятори результату (6x2 вектори по 8 float).
    *   2 регістри (YMM12-YMM13) — для векторів матриці B.
    *   1 регістр (YMM14) — для широкомовного завантаження (broadcast) елемента матриці A.
*   **Інструкції:** Використовує `vfmadd231ps` (FMA) для обчислення 16 множень та додавань за один такт.

## 🔄 Пайплайн компіляції
1.  **Tenzo Dialect** -> **Fusion** (оптимізація графа).
2.  **Tiling** (розбиття великої матриці на блоки L3/L2 кешу).
3.  **Packing** (переупорядкування даних у пам'яті).
4.  **Vectorization** (перетворення на AVX2 інструкції).
5.  **LLVM JIT** (фінальна компіляція в машинний код).
